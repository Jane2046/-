# 文字清洗工具（源码与构建）

这是一个 **原生 C# / WinForms 单文件程序**，不依赖 Python，也不需要联网或安装运行库
（只用 .NET Framework 4.x，Windows 10/11 自带）。

## 交互流程

1. 复制要清洗的文字（Ctrl+C）
2. 双击 `文字清洗工具.exe`
3. 程序自动读出剪贴板内容 → 删除「起始文字」到「结束文字」之间的全部内容 → 结果写回剪贴板 → 窗口自动关闭
4. 直接 Ctrl+V 粘贴即可

如果剪贴板里没有文字，窗口会保持打开，可以直接在里面 Ctrl+V 粘贴后按回车清洗。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+V` | 粘贴新内容并立即重新清洗 |
| `Enter` / `Ctrl+Enter` / `F5` | 重新清洗 |
| `Ctrl+S` | 打开设置 |
| `Esc` | 关闭窗口 |

## 设置

右上角「设置」（`Ctrl+S`）里有两项：

**① 要删除哪一段内容？**

- 「起始文字」/「结束文字」：自定义要删除的范围（结束文字留空 = 从起始文字一直删到结尾）
- 首次运行预填 `You are a helpful AI assistant` → `Do you understand?`，可直接改成任意内容
- 旧的「内置组合」单选已移除，只保留自定义

**② 清洗完成后，在文本最后自动加上下面这段话**

- 勾选后：清洗结果末尾会**空一行**再接上你填写的这段话（可多行）
- 不勾选、或内容留空：不追加
- 勾选状态与内容都会保存，下次打开仍然有效

保存后立即生效；设置文件位置：`%APPDATA%\文字清洗工具\settings.json`（DPAPI 加密，仅当前用户可读）。
若该目录不可写，会自动改为保存在 exe 同目录，并在保存失败时弹窗提示。

## 匹配规则

- 忽略大小写
- 标记内部的空格可以匹配原文里的任意空白（含换行），例如标记 `Do you understand?`
  可以匹配原文中的 `Do you\r\nunderstand?`
- 标记两侧如果被引号 / 书名号包着（`“…”`、`"…"`、`「…」`），引号会一起删掉
- 标记末尾的句末标点（`. ? ! 。 ？ ！`）会一起删掉
- 找不到**起始**标记 → 原文不动，只在状态栏提示
- 找不到**结束**标记 → 为安全起见原文不动并提示（避免误删整篇）
  （只有明确把「结束文字」留空时才会删到结尾）

## 只删除，不改排版

**程序只做一件事：删掉「起始文字」到「结束文字」之间的内容。**
原文其余部分（题号 `1.`、分值 `1 point`、换行、空行、缩进、行尾空格、制表符）
**一律保持原样**，不做任何重排、补空行或压缩空行。

删除边界只做最小清理：

1. 删除区紧贴的**孤立括号 / 引号**（标记被 `(…)`、`"…"`、`「…」` 包住时的残留）一并去掉
2. 删除区紧贴的**行尾空格**与**所在行的换行**去掉
3. **删除位置留一个空行**（前后都还有内容时），把被删段落的位置空出来：
   `第一段文字` + 删除区 + `第二段文字` → `第一段文字` / 空行 / `第二段文字`
4. 行内删除（被删内容里没有换行）用**一个空格**衔接，不额外造行：
   `Before. To uphold Coursera's policy (see related topics.) After.` → `Before. After.`
5. 删除区在开头或结尾时，不在文首文末留空行
6. 其余换行、空行数量原样不动

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本会：

1. 把 `CleanText.cs` 补成带 BOM 的 UTF-8（否则 csc 按 ANSI 解析，中文字符串会乱码）
2. 用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 编译成
   `..\文字清洗工具.exe`（约 47 KB，单文件、无依赖）
3. 编译一个控制台版本跑 `--selftest`（19 个用例：13 个清洗逻辑 + 6 个追加文字用例）并打印结果

调试用命令行参数：

- `--selftest`：跑单元自检，结果写到 exe 同目录 `selftest.txt`
- `--clean <文件> <起始标记> <结束标记>`：无界面清洗文件，输出到 `<文件>.out`
  （同目录还会写一个 `<文件>.meta`，记录删除段数与标记命中情况，便于核对）
